# Unverified

One row per claim the code makes that could not be proven on a development
machine, what it needs to be proven, and the exact command that would prove it.
This is the test plan for the session where the accounts, the model keys and the
cloud project are wired up — not a list of things believed to be broken.

A row leaves this file when someone runs its command and sees its expectation.
If the expectation turns out to be wrong, that is a finding and an issue, not an
edit to make the row pass.

Each row has an id of its own (U1, U2, …), which the rest of the documentation
cites; a row keeps its id when it moves to Closed.
