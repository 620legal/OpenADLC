# Decisions

One file per decision that would otherwise be re-argued: `NNNN-short-title.md`.

A decision record says what was decided, what it rules out, and what would make
it worth revisiting. It is written once and not edited afterwards — a decision
that changed is a new record that supersedes the old one, because the point of
the file is the reasoning available at the time.

The template is `0000-template.md`.

The decisions OpenADLC was built on so far are the D-table in
[platform-plan.md](../platform-plan.md#12-decisions), one row each. A decision
taken from here on is a record in this folder; the plan's table links to one
only where it changed a decision the table already had (0003, from D5 and D12;
0004, from D7). The records:

- [0055](0055-the-boards-grouping-is-chosen-in-appearance-and-the-palette.md): the board's toolbar has no By stage | By state switch; the view (`openadlc.board.view`, read as ADR 0027 has it) is chosen in Settings → Appearance's Board row (admins, ADR 0053 stands) and with ⌘K's `board-view` command, "Group the board by state" / "… by stage" (everyone), which saves it and goes to the board; `saveView` dispatches `VIEW_EVENT`, and `onViewChange` hears it and other tabs' `storage` events, so a mounted board follows; By state draws one `role="status"` line with a "Group by stage" button.
- [0056](0056-a-cards-sheet-holds-everything-its-card-does.md): a Needs-you card's Show more sheet draws everything its face does, never less; a held approval's, merge's or promote's panel is drawn in both, sharing one `usePanelState()` owned by `NeedsCard`; the sheet's copy is `full` (reviews whole, no sign-in polling, which the card's mounted copy does); the sheet's title wraps (`data-subject`, `break-words`), and `hasMore` is true for a held approval with any review summary.
